Ask the docs

A production-style RAG system on AWS. Ask a question and get an answer that cites the documents it came from, or an honest "I don't know". One system, two separate knowledge bases:

40 pages of the FastAPI tutorial. Try an example, or open the chat bubble in the bottom-right corner and ask anything.

Support articles, policies (two of them PDFs) and a staff handbook of Glimmerwick Gadgets, a fictional company invented for this demo.

What it does

Markdown documents are uploaded to S3, split into heading-aware chunks, embedded and stored in Amazon S3 Vectors. A question is embedded the same way, the closest chunks are retrieved, and a language model answers only from them, citing sources as [1], [2]. If nothing retrieved is close enough, the system refuses before calling the model at all.

Everything is serverless and defined in Terraform, so idle cost is close to storage only. The AI provider is a single setting (Gemini today, Amazon Bedrock when quota allows).

Architecture

This page is served privately from S3 through CloudFront. Both Lambdas run with least-privilege IAM, and the AI provider key lives only in SSM Parameter Store.

How well does it work?

40 questions written from the docs (32 answerable, 8 not), measured against the live API. The only change between the two runs is the refusal threshold, tuned from the first run.
